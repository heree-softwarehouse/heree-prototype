# Heree Mobile UI Kit

A high-fidelity recreation of the Heree iOS app. Mirrors the canonical `source/Heree - Rejestracja.html` with a modular component breakdown.

## Screens (click-through prototype in `index.html`)
1. **Splash** — pulsing coral pin + *heree.* wordmark + tagline
2. **Phone** — Polish number entry with custom numeric keypad, country chip, consent
3. **OTP** — 6-digit code with iOS-style autofill simulation and shake-on-wrong
4. **Loading** — verification checklist
5. **Dashboard** — map top + report feed in burgundy bottom sheet

## Files
- `index.html` — full interactive prototype (390×844 device frame)
- `components.jsx` — all React components (scenes + primitives + icons)
